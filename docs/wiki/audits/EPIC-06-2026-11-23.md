- **Stryker's command runner counts any non-zero exit as a kill.** A flaky
  case in a run's `<FILES>` would hide a survivor. No run here showed a
  failed baseline, but each baseline ran once.
- **"Not re-run" is equivalent to "re-run" for the four carried-forward
  runs only because neither their mutated file nor any file in their
  `<FILES>` changed.** That was checked with `git diff --stat c5a07a2 HEAD`
  over `shared`, `src` and `supabase/functions`. A changed shared helper
  imported by those suites (outside those paths) would break it; none is
  imported from outside `src` and `shared`, by reading.
- **The milliseconds survivors (`recurrence.ts:76:16`, `:78:5`) are harmless
  only while no stored instant carries sub-second precision**, as in 11-21.
- **`TimeGrid.tsx:141:59` is equivalent only while `clipped` and the map
  passed to `overlapColumns` are the same array of the same objects.**
- **CAL-084's severity assumes the Undo of an occurrence move is used.** How
  often was not measured.
