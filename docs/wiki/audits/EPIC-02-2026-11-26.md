### E-REASON: consequences reasoned, not run

- **N01.** `KindsPage` passes `open` unconditionally (`:76-82`) and shows the
  editor while `editing !== undefined` (`:75`). Only `onClose` sets it back.
  `KindEditor` calls `onClose` on a successful save (`:302`), on Cancel
  (`:345`) and, through `Dialog`, on Escape (`src/ui/Dialog.tsx:47-53`, which
  prevents the browser's own close). So with `:80` emptied, none of the three
  closes it. The one Save test on the page (`KindsPage.test.tsx:231`) waits
  for "Edit Films" in the list and never asks whether the editor closed.
- **N02.** The editor initialises its colours once, when it mounts
  (`KindEditor.tsx:215-220`), from `unusedPair` over the kinds it is given
  (`:62-68`). While the store is loading, those are `[]`, so it starts on
  `DEFAULT_KINDS[0]` (Movies, `#7E3FB8`, `src/kinds/defaultKinds.ts:17`),
  used or not.
- **N03, N04.** The editor's `isHex` (`:35`, `:42`) decides whether the
  preview calls `chipText` (`:153-156`) and whether `editHex` calls
  `darkCounterpart` (`:257`). Both reach `relativeLuminance`, whose `HEX`
  (`colour.ts:10`) is anchored and throws `RangeError` (`:19-21`).
  `grep -rn "ErrorBoundary\|componentDidCatch" src --include=*.tsx` over
  non-test files finds nothing. So by reading, a render-time throw unmounts
  the root and the screen goes blank.
- **N05.** The only picker test (`KindEditor.test.tsx:213`) asserts the
  picker exists with `type="color"`. Nothing fires a change on it.
- **N06, N07.** Every preview test reads the `p[data-preview]` text
  (`KindEditor.test.tsx:151-155`), not the swatch above it.
