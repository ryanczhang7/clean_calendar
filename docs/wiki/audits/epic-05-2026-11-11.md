**Classification of the four survivors.**

- **Gap, filed as CAL-069:**
  - **G41.** `gemini_test.ts` never reads `confidence.type`. CAL-051 AC-2 reads
    the confidence *properties*.
  - **G29.** `gemini_test.ts:112` reads `missing.type` and
    `missing.items.enum`, never `missing.items.type`. G42 (the enum dropped) is
    killed.
- **Equivalent, H71.** Without `typeof body === "object"`, a number or string
  body reaches `Object.hasOwn(body, "image")`, which is `false` for primitives,
  and then `fields.text`, which is `undefined`. So the request is 400 either
  way. The `null` case is still caught by `body !== null`.
- **Acceptable, H76.** It hashes the trimmed text. `input_hash` is a privacy
  stand-in for the input in an audit column (`architecture.md:52`). Nothing
  in-app reads it, and only a text with leading or trailing whitespace is
  affected. Not filed.
