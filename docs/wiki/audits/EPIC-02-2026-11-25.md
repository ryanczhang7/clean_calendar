## Decided

1. **The committed `mutation` gate still cannot start** (the seventh audit in
   a row). The same four git-listing tests in `src/geminiBoundary.test.ts`
   and `src/deploy/noSecrets.test.ts` fail in Stryker's sandbox dry run. Not
   filed here: the fix is `stryker.config.mjs` or `project.conf`, the PO's.
   Rests on E-GATE.
2. **The seed, the owner guard, the walkthrough gate and the repositories are
   well pinned.** Over `seedKinds.ts`, `defaultKinds.ts`, `kindsStore.ts`,
   `onboarding.ts`, `kindActions.ts`, `data/kinds.ts` and `RequireOwner.tsx`,
   236 mutants: 224 killed, 12 survive, and every one of the 12 is equivalent
   or confined to a test-only factory. Seeds once, never over existing rows
   (soft-deleted included), and the 23505 re-read: every behavioural mutant is
   killed. Rests on E-STRYKER and E-CLASS.
3. **The production seed path has one weak spot, judged not worth a story.**
   `cachedStores.ts:122` (`if (seeded !== null)` -> `if (false)`) survives the
   whole unit project. The cost is one extra GET and one extra full sync per
   `RequireOwner` mount after the first. The seed itself stays idempotent,
   because `ensureDefaultKinds` finds rows and reports `existing`. Not filed.
   `:125` (skipping the `bulkPut` of the seeded rows) is killed, but only by
   `AppShell.test.tsx`. `cachedStores.test.tsx` does not pin it. Rests on
   E-WHOLE (W12, W13).
4. **The keyboard shortcut is the highest-impact gap. Filed as CAL-091.**
   `KindLegend.tsx:68` dropped (`if (false) return;`), so that **every** key
   pressed outside a text field toggles the legend (Tab, Enter, the arrows),
   survives all 3423 unit tests. The same story takes `:98`. There, the
   deferred focus return fires even when the outside pointer put focus on
   another control, so that control loses its focus. Rests on E-WHOLE (W10,
   W11).
5. **The kind editor's submit path is unpinned. Filed as CAL-092.** Four
   mutants survive the whole unit project. `:307` drops `preventDefault()`, so
   in a real browser every Save submits a `method`-less form and reloads the
   app. `:308` drops the busy guard, so two quick presses send two
   `addKind`s. `:299` leaves `busy` set after a refusal, so a refused save
   cannot be retried. `:276` sets the alert strip at the start of every save.
   jsdom cannot see a navigation, and no e2e spec saves a kind (E-E2E), so
   `:307` is unguarded at every level that runs today. Rests on E-WHOLE (W06
   to W09).
6. **The editor's opening state and the dark group's Custom… are unpinned.
   Filed as CAL-093.** `:226` (`useState(true)` for the delete confirmation)
   opens "Delete the kind {name}?" over every Edit, and survives. `:247`
   (`chooseCustom` treats every theme as light) makes the dark group's
   Custom… do nothing visible to the dark group, so a custom dark colour cannot
   be entered. That also survives. Rests on E-WHOLE (W04, W05).
7. **The colour walks are pinned only on greys, greens and blues, and the
   4.5 floor only from below. Filed as CAL-094.** The red-is-max hue branch
   (`colour.ts:68`) can be dropped with every test green. A red custom colour

   E-IMPACT.

   deferred verifications, CAL-007's five, CAL-008's three), each at the

9. **Every assertion that passed on arrival is earned.** CAL-006's three

### E-BRUTE: exhaustive checks behind the equivalence calls

Each script imported the **real** module
(`file:///D:/clean_calendar/src/domain/colour.ts`, with Node 24's type
stripping) and looped over all 16,777,216 `#RRGGBB` values. 15.6 s for the
first:

```
{ n: 16777216, ties: 0, lum42: 0, at450: 38062, ex: [ '#006EFE', '#006FFB', '#0071F4', '#0072F0', '#0073EC' ] }
{ n: 16777216, exactly3_light: 0, exactly3_dark: 0 }
```

- `ties`: `contrast(hex, "#1B1B1F") === contrast(hex, "#FFFFFF")` for no
  colour, so `colour.ts:40` `>` -> `>=` is **equivalent**.
- `lum42`: `relativeLuminance(hex) === 0.42` for no colour, so `:133` `>=` ->
  `>` is **equivalent**.
- `at450`: 38,062 colours have a rounded best ratio of exactly 4.50. So
  `:113` and `KindEditor.tsx:230` are **not** equivalent.
- `exactly3_*`: no colour is at exactly 3:1 unrounded against either surface,
  so `KindEditor.tsx:190` `<` -> `<=` is **equivalent**.

**Unrepresentative if** the colour inputs can be other than `#RRGGBB`. The
`HEX` regex refuses everything else (`colour.ts:10`).
