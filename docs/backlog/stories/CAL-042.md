## Context

EPIC-03, from `docs/wiki/audits/epic-03-2026-10-21.md` (Decided 5;
Evidence E-STRYKER `src/calendar/CalendarPage.tsx`, hand mutants H18, H20).

CAL-011 made the page own the month selection and the URL, and CAL-012 made
it open the event sheet. Stryker, judged by the whole unit suite, left these
alive in `src/calendar/CalendarPage.tsx`:

- **`sameMonth` ignores the year** (`:80`, the `getFullYear` comparison →
  `true`). A selection of 14 Oct 2026 is kept when the page shows October
  2027, so the grid's single tab stop is a day that is not in the grid. One
  Stryker run recorded a "kill" of this mutant. It was a 5,000 ms timeout in
  the unrelated `WalkthroughPage.test.tsx` (audit E-FLAKE, H20: 172/172
  green when re-run).
- **Every in-month selection pushes history** (`:294`,
  `if (!sameMonth(date, first))` → `if (true)`). Each arrow key inside the
  month navigates to the same URL and adds an entry, so Back walks back
  through key presses.
- **The shared selection is not re-synced on a period change** (`:357`
  `periodKey` → `""`, `:366` deps → `[]`). The toolbar's view switcher reads
  the shared selection. After Next month it would still hold the old month's
  day, so switching to Week opens the wrong week.
- **`N` and Add pass no opener** (`:83`, `focused` → `() => undefined`).
  Closing the sheet then leaves focus nowhere instead of returning it to the
  cell or the Add button. The suite pins focus return for a cell click and a
  chip (`:1154`, `:1167`), not for `N` or Add.

Test-only: the shipped page is believed correct, so each new assertion
passes on arrival and is earned by its mutant.

Required gate that would fail if this broke: `unit`.

## Acceptance criteria

- **AC-1** - Given the page at `/month/2026-10` with 14 October selected,
  when it navigates to `/month/2027-10`, then 14 October 2026 is not the
  selection: the selected cell is one of the October 2027 grid's cells (the
  1st, by Block 10's rule, unless the injected today is in October 2027). A
  test fails when `sameMonth`'s year comparison is `true` (`:80:3`).
- **AC-2** - Given the month at `/month/2026-10`, when `ArrowRight` moves the
  selection within October, then the router's history has no new entry
  (the history length or index is unchanged, and the location is not
  re-pushed). When the selection leaves the month, then there is one new
  entry. A test fails when `:294`'s condition is `true` (audit H18).
- **AC-3** - Given the full shell at `/month/2026-10` with 14 October
  selected, when Next month is pressed and then the view switcher's Week,
  then the URL is the week holding the November selection, `/week/2026-10-26` (1 Nov 2026 is a Sunday; its week starts Mon 26 Oct),
  not of 14 October. A test fails when `periodKey` is `""` (`:357`) or the
  effect's deps are `[]` (`:366`).
- **AC-4** - Given a focused month cell, when `N` is pressed and the sheet is
  closed with no change, then focus is back on that cell; and given the
  phone day list's Add button, when it opens the sheet and the sheet is
  closed, then focus is back on Add. A test fails when `focused` returns
  `undefined` (`:83`).
