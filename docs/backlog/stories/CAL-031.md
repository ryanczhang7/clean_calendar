## Context

EPIC-08: one end-to-end run of the walking path against the local stack, so
that the path the owner uses every day cannot regress unnoticed, plus the
browser-only checks `accessibility.md` ("What tests assert", Integration) and
earlier stories deferred here because jsdom cannot see them: responsive
layout at 375 and 1280, the bottom sheet, focus return, reduced motion, and
axe. It runs against `supabase start`, `supabase functions serve` with
`GEMINI_API_BASE` pointed at a local stub, and `vite preview`.

Required gate that would fail if this broke: `integration`, optional
repo-wide, so it is in `required_gates`.

## Acceptance criteria

- **AC-1** - Given a fresh local database and an owner session injected by the
  session fixture (a local Auth user for the seeded owner e-mail), when the
  app opens, then the walkthrough shows eleven kinds; "Done, show my calendar"
  lands on this month with the empty-month card.
- **AC-2** - Given the month, when an event is created from a day cell in the
  Restaurant reservations kind, then its chip is on
  that day in the kind's light colour, and it is still there after a reload.
- **AC-3** - Given `/capture`, when the stubbed assistant returns a fixed
  flight proposal with the end time missing, then the confirm screen marks End
  as missing, saving after filling it puts a Flights-coloured chip on the
  proposed day, and the stub received exactly one request.
- **AC-4** - Given the viewport 375×812, when the month and the sheet are
  shown, then the page has no horizontal scroll, each bottom-nav tab is at
  least 44×44 px, and the sheet opens as a bottom sheet; at 1280×800 the
  bottom nav is hidden and the sheet docks at 400px.
- **AC-5** - Given axe (`@axe-core/playwright`, tags `wcag2a`, `wcag2aa`,
  `wcag21aa`), when it runs on sign-in, the walkthrough, the month with one
  event in each of the eleven kinds in light and in dark (`emulateMedia`), the
  week with the sheet open, the legend, capture, confirm with a missing field,
  and the edit-scope dialog, then it reports zero violations.
- **AC-6** - Given `reducedMotion: 'reduce'`, when the sheet opens, then its
  computed `transition-duration` is `0s`; and opening a chip then pressing
  Escape leaves focus on that chip.
