## Context

EPIC-06, brief §4.5: "edit one occurrence or the series". `architecture.md`,
"Overrides": editing one occurrence writes an `event_overrides` row keyed by
the occurrence's original date; deleting one writes `cancelled = true`;
editing the series edits the `events` row and overrides still win where they
exist. The edit-scope dialog asks which (`components.md`, "Edit-scope
dialog"; copy `voice.md`, "Dialogs"). Override writes go through the outbox
(CAL-015) like every other write.

Required gate that would fail if this broke: `unit`.

## Acceptance criteria

- **AC-1** - Given an occurrence of a series, when an edit is saved, a move is
  dropped, or Delete is pressed, then an `alertdialog` "Change which events?"
  (or "Delete which events?") offers "This event only" (selected, focused)
  and "All events in the series" with Cancel and Save (or Delete); for a
  non-recurring event no dialog appears.
- **AC-2** - Given "This event only" on an edit, when it is confirmed, then one
  override is written for that occurrence's original date holding only the
  changed fields; the other occurrences are unchanged and the edited one shows
  the new values.
- **AC-3** - Given "This event only" on a delete, when it is confirmed, then an
  override with `cancelled = true` is written, that occurrence disappears, and
  "Deleted {title}" with Undo is shown; Undo removes the cancellation.
- **AC-4** - Given "All events in the series" on an edit, when it is confirmed,
  then the series row is updated, every occurrence without an override shows
  the change, and overridden fields of overridden occurrences keep their
  override values.
- **AC-5** - Given "All events in the series" on a delete, when it is confirmed,
  then the series is soft-deleted, every occurrence disappears, and "Deleted
  {title} and all its occurrences" with Undo is shown.
- **AC-6** - Given "All events in the series" on a move by N days, when it is
  confirmed, then the series start moves by N days, the helper "Moving the
  whole series moves every occurrence by the same amount." was shown, and the
  dialog's Escape cancels without writing.
