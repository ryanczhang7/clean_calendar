## Context

EPIC-02. Source: `docs/wiki/audits/EPIC-02-2026-11-25.md`, Decided 7 and
Evidence `### E-WHOLE` (W01 to W03), `### E-BRUTE` and `### E-IMPACT`. The
colour rules CAL-007 built (`src/domain/colour.ts`, Contract Block 1) are
correct today. Two gaps let them be broken with all 3423 unit tests green:

- **W01, `colour.ts:68`, the hue branch for a colour whose largest channel
  is red.** Every pinned walk input is a grey, a green or a blue (`#808080`,
  `#777777`, `#7F7F7F`, `#7E7E7E`, `#3C8D40`, `#1565C0`, `#2E7D32`). With
  `if (max === r)` replaced by `if (false)`, a red keeps its lightness but not
  its hue. `darkCounterpart("#E53935")` becomes `#EE8AF0` (magenta) instead
  of `#F19593`. `nearestPassing("#D9534F")` becomes `#D44BD8` darker instead
  of `#DB5B57` lighter. The result still passes its floor, so nothing
  downstream notices. In the product, a red custom kind silently gets a pink
  dark-theme colour, or a "Fix it" that turns it magenta.
- **W02 and W03, the 4.5 floor at exactly 4.50.** `colour.ts:113`
  (`textPasses`) and `KindEditor.tsx:230` (`readable`) each use `>=`. Either
  can become `>`, because every pinned control is below 4.5 or well above it.
  38,062 colours have a rounded ratio of exactly 4.50 (E-BRUTE). Under W02,
  "Fix it" walks past a colour that already passes (`#108D40` -> `#0F853C`
  instead of `#10893E`). Under W03, the editor disables Save for a 4.50:1
  colour while showing no "hard to read" message and no Fix it (`:158` uses
  `<`), so the owner is stuck with no explanation.

This is a test-only story: the production code is right, and the tests pin it.
Each new test passes on arrival, so it has to be earned by putting the
audit's mutant back (see `## Deferred verifications`).

Required gate that would fail if this broke: `unit` (required). It runs both
test files.

## Acceptance criteria

- **AC-1** - `darkCounterpart("#E53935")`, a colour whose largest channel is
  red, is `#F19593`.
- **AC-2** - `nearestPassing("#D9534F")` (best text contrast 4.33:1, so
  below the floor) is `{ hex: "#DB5B57", direction: "lighter" }`.
- **AC-3** - `nearestPassing("#108D40")` (4.28:1) is
  `{ hex: "#10893E", direction: "darker" }`, and
  `chipText("#10893E")` is `{ text: "#FFFFFF", ratio: 4.5 }`. A colour at
  exactly 4.50:1 is the walk's stopping point, not a step it walks past.
- **AC-4** - Given the "Add kind" editor with the name "Pine", when the light
  theme's custom hex is set to `#10893E` (exactly 4.50:1), then the light
  preview reads `Text contrast 4.50:1 · Against background 4.50:1`, no "Text
  would be hard to read" message is shown, and Save is enabled.

  editor disables Save when it is < 4.5"). `#10893E` is 4.4969 unrounded
  and passes by that rule. That is the shipped, documented rule and this
  story pins it; it does not reopen it (`## Notes`, PO decision 1).
