## Context

EPIC-05, brief §4.3: the app sends a booking e-mail's text to Gemini and gets
back a proposed event. Decided after the interview: the Gemini key is a
server-side secret and captures go browser → edge function → Gemini.
`architecture.md` ("capture function", "Capture"): the function verifies the
JWT and the owner e-mail, gives the model the owner's kind names, validates
the reply with a zod schema shared with the client (`shared/captureSchema.ts`),
records a `capture_jobs` row (hash of the input, never the input), and returns
`{proposal, confidence, missing, jobId}`. Model: `gemini-2.5-flash`
(`stack.md`), REST `generateContent` with a JSON response schema, raw `fetch`.

Required gates that would fail if this broke: `deno-test` (handler and Gemini
client with `fetch` stubbed), `deno-check`, and `unit` (the shared schema and
the boundary guard under Vitest).

## Acceptance criteria

- **AC-1** - Given a POST `{text}` with the owner's JWT, when the handler runs,
  then it calls `{GEMINI_API_BASE}/v1beta/models/gemini-2.5-flash:generateContent`
  once with the key in the `x-goog-api-key` header, `responseMimeType:
  application/json`, a `responseSchema`, and a prompt that contains the text
  and the owner's live kind names; and it returns 200 with `{proposal: {title,
  startsAt, endsAt, allDay, location, kindName}, confidence: {<field>: 0..1},
  missing: [<field>], jobId}` validated by `shared/captureSchema.ts`.
- **AC-2** - Given the model returns a `kindName` that is not one of the
  owner's live kinds, when the reply is mapped, then `kindName` is `null` and
  `kind` is in `missing`.
- **AC-3** - Given the model's reply fails the shared schema (malformed JSON, a
  missing key, `confidence` outside 0..1), when the handler runs, then it
  returns 502 `{error: 'unreadable'}` and the job row records the error.
- **AC-4** - Given no JWT, the handler returns 401; given a valid JWT for an
  e-mail other than `app_config.owner_email`, it returns 403. In both cases
  Gemini is never called and no job row is written.
- **AC-5** - Given any successful or failed call, when the job row is written,
  then it holds `input_kind 'text'`, the SHA-256 hex of the text, the model
  name, `status 'proposed'` (or the error), and `latency_ms`; the text itself
  appears in no column.
- **AC-6** - Given an empty text or one over 20,000 characters, the handler
  returns 400 without calling Gemini.
- **AC-7** - Given every source file under `src/` and `shared/` (enumerated with
  `bash scripts/classify.sh --list source`), when the boundary guard runs,
  then none contains `generativelanguage.googleapis.com` or `GEMINI_API_KEY`.
  *Control:* a probe file `src/__probe_gemini.ts` containing the host must be
  reported by the guard's scanning function.
