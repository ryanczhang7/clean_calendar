## Context

The first story of EPIC-01 (`docs/backlog/epics/EPIC-01.md`). It turns the
empty repository into the layout `docs/wiki/stack.md` describes - a Vite +
React + TypeScript PWA under `src/`, Deno edge functions under
`supabase/functions/`, code shared by both under `shared/`, Playwright specs
under `e2e/` - and makes every gate in `stack.md` real. `stack.md` is marked
**Unverified**: every command and version in it is researched, and this story
is where each is executed for the first time, observed failing on purpose, and
corrected where it has moved. Run under SCAFFOLD (`type: bootstrap`), so
nothing forces a test to exist; `## Scaffold inventory` is where the tests are
shown anyway.

Toolchain first: `/setup-environment` must have installed Node 22, pnpm 10,
Deno 2 and the Supabase CLI (`docs/wiki/environment.md`) before this story
starts. Docker is needed only to probe the optional `db` and `integration`
gates; if it is absent, say so in `## Gate probes` and leave those two probes
to the first story that requires them (CAL-004 for `db`, CAL-017 for
`integration`).

Required gates that would fail if this story's artefact broke: all of them -
`lint`, `typecheck`, `unit`, `coverage`, `deno-check`, `deno-test`, `build`.

**Version pins (PO decisions, numbered so the user can overrule them):**

1. **Node 24, not 22.** `/setup-environment` measured Node v24.19.0 installed
   and nothing on 22. Node 24 is the current LTS line, so `.nvmrc` says `24`
   and `engines.node` says `>=24`. `stack.md` is corrected to match. Reason to
   overrule: a hosting or CI image pinned to 22 - none is planned.
2. **Deno `^2.9`**, what winget installed (2.9.7). `stack.md` said 2.5.x.
3. **Vitest: the current major at install time**, as `stack.md` already

4. **Supabase CLI as a dev dependency** (`supabase` on npm), run as
