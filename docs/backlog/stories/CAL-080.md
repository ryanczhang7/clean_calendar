## Context

EPIC-06. Source: `docs/wiki/audits/EPIC-06-2026-11-21.md` (Decided 3,
Evidence E-STRYKER `small`, E-RECHECK R3 and R4b).

The edit-scope dialog (`src/events/EditScopeDialog.tsx`, CAL-025 Block 2) has
two radios. Its suite checks the default ("This event only", confirmed as
`"occurrence"`), a move to "All events in the series" (`"series"`), and that
every open starts on "This event only" again. Nothing checks going **back**:
choosing "All events in the series" and then "This event only" in the same
open. Two mutants of the first radio's `onChange` (`:75`) survive the whole
unit project:

- `onChange={() => setScope("occurrence")}` -> `onChange={() => undefined}`:
  the first radio can no longer be re-chosen; Save or Delete then confirms
  `"series"`.
- `setScope("occurrence")` -> `setScope("")`: neither radio is checked, and
  confirm sends `""`. `CalendarPage`'s `confirmScope`
  (`src/calendar/CalendarPage.tsx:321` and `:339`) tests `scope ===
  "occurrence"` and sends everything else to the series branch, so a chip
  or sheet Delete confirmed there soft-deletes **the whole series**
  (`removeEvent(series)`, toast "Deleted {title} and all its occurrences").
  `EventSheet`'s Save (`src/events/EventSheet.tsx:474`) tests `scope ===
  "series"` instead, so the same `""` there edits the one occurrence.

So a slip in that one line turns "I changed my mind, just this one" into an
edit or delete of every occurrence. Undo exists, which is why this is not
ranked above CAL-079.

Test-only: the shipped dialog is believed correct, so each case passes on
arrival and is earned by its mutant. Required gate that would fail: `unit`
(and `coverage`).

## Acceptance criteria

- **AC-1** - Given the dialog open with `kind="change"`, when the owner picks
  "All events in the series" and then "This event only" and presses Save,
  then "This event only" is checked, "All events in the series" is not, and
  `onConfirm` is called once with `"occurrence"`. A test fails under
  `s#onChange={() => setScope("occurrence")}#onChange={() => undefined}#` on
  `src/events/EditScopeDialog.tsx`, and under
  `s#setScope("occurrence")#setScope("")#`.
- **AC-2** - The same with `kind="delete"` and Delete: `onConfirm` once with
  `"occurrence"`, never `"series"`.
