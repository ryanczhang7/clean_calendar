## Context

EPIC-02. Source: `docs/wiki/audits/EPIC-02-2026-11-26.md`, Decided 3, and
Evidence `### E-STRYKER` (group `pages`) and `### E-WHOLE` (N01, N02).
CAL-008 built the "Event kinds" page (`src/kinds/KindsPage.tsx`, Contract
Block 3). It is correct today. The previous audit never mutated it: its
Stryker range `KindsPage.tsx:152-185` lies past the end of the 86-line file.
Two mutants now survive all 3444 unit tests:

- **N01, `KindsPage.tsx:80`, the editor's `onClose`.** With
  `onClose={() => setEditing(undefined)}` replaced by
  `onClose={() => undefined}`, the editor on `/kinds` never closes: Save
  sends the change and the dialog stays open, and Cancel and Escape do
  nothing. The page's only Save test (`KindsPage.test.tsx:231`, "a rename
  persists exactly as in the walkthrough") waits for the row to read "Films"
  and never asks whether the editor closed. No test on the page presses
  Cancel or Escape. No e2e spec saves a kind (previous audit, E-E2E).
- **N02, `KindsPage.tsx:42`, the "once the kinds are ready" guard.** With
  `if (status !== "ready") return;` replaced by `if (false) return;`,
  `?kind=new` opens "Add kind" while the store is still loading. The editor
  takes its starting colour once, when it mounts (`KindEditor.tsx:215-220`,
  `unusedPair` over the kinds it is given), so it starts on the first palette
  pair (Movies, `#7E3FB8`) even when a live kind already uses it. The only
  slow-store test (`:269`) uses `?kind={id}`, which this mutant cannot break,
  because no row matches until the store is ready.

This is a test-only story: the production code is right, and the tests pin it.
Each new test passes on arrival, so it has to be earned by putting the
audit's mutant back (see `## Deferred verifications`).

Required gate that would fail if this broke: `unit` (required).

## Acceptance criteria

- **AC-1** - Given `/kinds` with Movies and Gym, when Edit Movies is pressed,
  the name changed to "Films" and Save pressed, and the save succeeds, then
  no dialog named "Edit Movies" (or "Edit Films") remains open, and the list
  reads Films, Gym.
- **AC-2** - Given the "Edit Movies" editor open on `/kinds`, when Cancel is
  pressed, then the editor closes and nothing is saved.
- **AC-3** - Given the "Edit Movies" editor open on `/kinds`, when Escape is
  pressed, then the editor closes and nothing is saved.
- **AC-4** - Given `/kinds?kind=new` and a store that has not answered yet,
  no dialog is open. When the store then answers with Movies (`#7E3FB8`) as
  its only live kind, "Add kind" opens with Entertainment (`#BD8200` light,
  `#F5CC6A` dark), the first palette pair no live kind uses, checked in the
  Light and Dark groups.
